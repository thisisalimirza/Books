# Reference

## journal-entries/

The raw source material for this book. One file per entry (or per logical
batch), named `YYYY-MM-DD.md` or `YYYY-MM-DD-title.md`, unedited. This is the
ground truth — chapters are built *from* these, and should stay traceable
back to which entries they draw on.

Anything else that supports the book — photos, letters, external records —
goes here too, alongside `journal-entries/`.
