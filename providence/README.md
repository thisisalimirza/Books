# Providence

**Started:** 2026-08-22
**Target length:** TBD

## Logline

An autobiography built over time from journal entries — not written toward an
outline, but assembled and shaped from what was actually recorded as it
happened.

## Where it stands

Just scaffolded. No journal entries transcribed yet. Next step is dropping
entries into `reference/journal-entries/` and starting to see what periods,
threads, or turning points want to become chapters.

## How this book gets built

Unlike a book drafted forward from an outline, Providence works backward from
source material:

1. **Capture** — journal entries go into `reference/journal-entries/`,
   one file per entry (or per batch), dated `YYYY-MM-DD.md` or
   `YYYY-MM-DD-title.md`. Raw, unedited, exactly as written.
2. **Find the shape** — periodically reread what's accumulated and look for
   arcs: a period of life, a recurring struggle, a relationship, a turn.
   Note candidates in `outline.md`.
3. **Draft a chapter** — once an arc is clear enough, pull the relevant
   entries together into a numbered chapter file and write the connective
   tissue — the narration that turns entries into story.
4. **Chapters can be reopened** — as more journal entries accumulate, an
   earlier chapter may need revising in light of what came later. That's
   expected here in a way it wouldn't be in a book drafted straight through.
