# Reference

This book's seed material lives in `providence/substack-essays/`, not here
— those essays are published work with their own home, and this book pulls
from them rather than duplicating them. See `../outline.md` for which essay
feeds which chapter.

Use this folder for material that's specific to *this* book and doesn't
belong in Providence: sources for claims made in the diagnosis chapters
(the CGM/pulse-oximetry/liquid-biopsy adoption-timeline research already
partially compiled in `why-is-medicine-so-anti-abundance`), interview notes,
data on physician compensation or technology-adoption lag, etc.
